# Market terminal audit — 10 September 2026

Audited baseline: `424c668dba99041e4de1daa807b8e6c157daaba1`.

This audit covers calculation engines, input validation, Streamlit reporting, public-data provenance and Excel/R outputs. It corrects reproducible defects within the existing educational models. It does not certify production pricing or introduce product upgrades.

## Corrections

- **Bond dates and day counts:** independently anchor coupon dates to maturity, preserve month-end across February, use actual coupon reference periods for ACT/ACT bond accrual and discounting, prorate a short first coupon consistently, and apply February-end rules for US 30/360. A regular 6% semiannual bond now prices at 100 at a coupon date when YTM is 6%. Missing columns, dates and fractional coupon frequencies produce validation errors.
- **Drawdown:** include initial wealth before the first return in Python and R. A first-period loss of 20% is now a 20% drawdown, rather than zero. A complete first-period loss remains a 100% drawdown rather than NaN.
- **Portfolio risk:** use the selected annualization frequency for absolute risk contributions as well as summary volatility. Select the CVaR tail before flooring losses at zero. Record the confidence level and avoid falsely labelled 95% exports for alternative levels. Preserve undefined Sharpe/contribution percentages for zero-volatility portfolios while keeping the page usable. Cash receives zero price shocks under the demo scenarios.
- **Repo margin:** distinguish cash-equivalent variation margin from securities dirty market value. With a 10% haircut, an 18-unit cash-equivalent deficit requires 20 units of additional securities. Both posting and returning collateral reconcile. Threshold, MTA and rounding remain cash-equivalent conventions; refinancing haircut stress stays separate.
- **European options:** retain negative time value when theoretical value is below immediate intrinsic value. Display values at the exact selected inputs, independent of which sensitivity axis is viewed; include the exact input in chart grids.
- **Structured products:** reject non-finite or negative performance ratios and protection barriers above initial value. Respect the basket-specific correlation boundary in sensitivities and disclose requested versus applied values. Record the actual evaluated path count. Hide cached valuation results after inputs change. Explain that the redemption-only valuation contract is separate from the Athena/Phoenix payoff terms.
- **Public data:** request closes with dividend auto-adjustment disabled explicitly. Preserve observation dates/timestamps separately from retrieval time. Do not invent a zero return when the previous close is missing, accept invalid latest prices, or replace failures with cached success labels. Refresh bypasses cache; callers cannot mutate cached quotes. Synthetic Treasury fallback data is labelled as synthetic, including the UI warning and commentary.
- **Input/report integrity:** reject non-finite values at the affected calculation boundaries and negative long-only weights. Handle malformed uploads with readable errors. Export formula-like uploaded labels as text, with automatic formula and URL conversion disabled for all four Excel reports.
- **Presentation:** identify static home insights and R outputs as examples, explain public-data context and portfolio rebalancing assumptions, and remove inaccurate claims that all data is synthetic or haircut resets directly cause contractual VM.

## Validation

The baseline suite passed 343 tests. The completed audit suite passed **393 tests** on 10 September 2026, with no failures or skips. Added financial identity, adversarial-input and executable Streamlit regression tests cover the defects above, including all six default pages, monthly risk-contribution reconciliation, zero-volatility portfolios, cached valuation invalidation and Python/R numerical parity. The standalone R report also completed successfully, and `git diff --check` passed.

Run the complete suite with `python -m pytest -q`. Run the R companion with `Rscript r_analytics/portfolio_performance_report.R`. The R parity test skips explicitly if R is not installed. No network calls are required for the automated quote tests; provider failures and cache behavior are mocked. Regenerated drawdown CSV/chart assets accompany the R fix.

## Remaining model limits

- Bond calendars, ex-coupon treatment, bespoke long stubs, calibrated curves and OAS remain outside the model. Maturity month-end is an explicit convention inferred from the available contract fields.
- Portfolio inputs must share a currency basis; total-return analysis needs distribution-adjusted prices. Stress classification remains a documented asset-name heuristic.
- Monte Carlo results depend on chosen parameters and sampling error. They are neither market-calibrated prices nor empirical probability forecasts. The final qualifying observation is included in the reported autocall event.
- Public quote tests validate adapter behavior, not third-party feed accuracy, availability or latency. Retrieval time is not proof that a quote is current. The deployed Streamlit service must receive the branch changes before its behavior changes.
- Streamlit currently emits existing `use_container_width` deprecation warnings; width API migration is separate from this calculation audit.
